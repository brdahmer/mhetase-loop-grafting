# MHETase MD and QM/MM simulations

Repository containing files and scripts for classical and hybrid molecular dynamics simulations of the *Ideonella sakaiensis* MHETase.

The repository is associated with the following paper:
B. R. Dahmer, A. P. Primaz, J. C. de Lima, J. F. R. Bachega, T. Wymore, L. F. S. M. Timmers; *Loop Grafting from a Thermophilic Metagenomic Homologue Suppresses Local Unfolding in Ideonella sakaiensis MHETase*. XXXX **YYYY**; https://doi.org/10.1021/xxxxx


The classical MD simulations were run with GROMACS. Post-processing and analyses were performed with standard GROMACS tools. Global and per-residue fraction of native contacts were analyzed with MDTraj, generalized order parameters were calculated with MOPS2. Hybrid QM/MM simulations were run with EasyHybrid3, a free and open source graphical user interface for the pDynamo3 suite.
